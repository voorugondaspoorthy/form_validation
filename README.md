Contact Form with JavaScript Validation

A simple, elegant, and responsive Contact Form built using HTML5, CSS3, and JavaScript. This project combines a warm burgundy and cream colour palette with interactive form validation to create a clean and user-friendly experience.

🌷 Project Overview

The Contact Form allows users to enter their personal details and send a message through a beautifully designed interface. JavaScript validates the entered information and displays appropriate error or success messages.

🎨 Design Highlights

- Elegant burgundy and cream colour combination.
- Clean and minimal user interface.
- Rounded input fields and a stylish Submit button.
- Responsive layout for different screen sizes.
- Interactive input focus and hover effects.

🚀 Key Features

- Name Validation: Checks whether the name field is empty.
- Email Validation: Checks whether the email address is valid.
- Phone Validation: Checks the phone number format.
- Subject Validation: Ensures the subject field is filled.
- Message Validation: Checks whether the message is provided.
- Error Handling: Displays helpful messages for invalid inputs.
- Success Feedback: Displays a confirmation message when all required fields pass validation.

🛠️ Technologies Used

Technology| Purpose
HTML5| Creating the form structure
CSS3| Styling and responsive design
JavaScript| Form validation and interactivity

💻 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.
4. Enter your details in the form.
5. Click the Submit button to test the validation.
